# AgentHEP：两篇论文的学习网络

准备对象：与 Andy 的首次讨论。阅读基准是用户上传的两个版本：

- **AgentRivet**，arXiv:2606.13535v4，2026-09-14，14 页。
- **MadAgents**，arXiv:2601.21015v5，首页同时标有 2026-09-14，61 页。

这里所有页码均指上传 PDF 的页码。本包不声称反映软件仓库的最新状态，也没有运行两个原框架。

## 内容

- `reading_workbook.md`：完整节点地图、精读定位、互相连接的案例、自测及参考思路。
- `validation_micro_lab.ipynb`：两个仅依赖 Python 标准库的教学微实验；没有 API、模型调用或 HEP 软件安装。数值是人为构造的教学数据，不是论文实验结果。
- `meeting_notes.md`：可直接填写的会前理解笔记；不要求制作 slides。

## 使用方式

主干是 **物理任务 → 控制与信息流 → 失败与证据 → 评价 → 研究问题**。

不按钟点推进。一个节点读到能用自己的话说明一个具体例子，就可以进入下一个节点；卡住时回到对应原文或带着问题继续对话。支线可以在会后继续。

MadAgents 的正文、Appendix C 改进版、Appendix E Claude Code 实现属于不同阶段，阅读时要分开记录。蓝色等着色框内的大量内容是 agent 的输出，不应直接当成物理教材。

## 一个不依赖“读完几页”的会前完成标准

能说清两套工具的输入和输出；能追踪各自一个成功案例和一个失败案例；能区分作者展示的结果与自己想验证的假设；带一两个有依据的研究兴趣与开放问题。
